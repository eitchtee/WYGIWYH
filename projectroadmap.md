# FinanceTracker Project Roadmap

## Project Overview
FinanceTracker is a financial tracking application designed to help users manage their income, expenses, and overall financial activity.

## Sprint 1: Basic Functionality
- Create the main Python program.
- Build the main menu.
- Add an option to record expenses.
- Add an option to record income.
- Add an option to exit the program.

## Sprint 2: Financial Tracking
- Display recorded income.
- Display recorded expenses.
- Calculate the user's remaining balance.
- Improve data organization.

## Sprint 3: Testing and Improvements
- Test all program features.
- Fix errors and bugs.
- Improve the user interface.
- Verify that financial calculations are accurate.

## Final Goal
Complete a functional beginner-friendly financial tracking application that allows users to record and manage their income and expenses.
